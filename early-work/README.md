# Early Work

The first two valuation tools I built in Excel VBA, in 2025. Both led to [Model RG](../models/model-rg/), which is where the current work lives. They're kept here to show where it started.

| Project | Built | What it does | Where it went |
|---|---|---|---|
| [Discounted cash flow model](dcf-model/) | September 2025 | Generates a formatted DCF template for any forecast period, plus a quick-valuation form that returns NPV and IRR | Superseded by Model RG |
| [Monte Carlo simulation engine](monte-carlo-simulation/) | October 2025 | Simulates project NPV with discrete, triangular and uniform inputs and plots the distribution | Rebuilt in Model RG with correlated draws, autocorrelation and five distributions |
